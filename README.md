# ECOM DZ STORE

An open-source e-commerce platform built with PHP and [Kirby CMS](https://getkirby.com/), utilizing a fast and secure flat-file architecture to provide seamless online store management.

## 🚀 Features
- Fast and secure flat-file architecture (No database required)
- Custom User Dashboard via Kirby Panel
- Product & Inventory Management
- Multi-language Support

## 🛠️ Prerequisites
Before you begin, ensure your local environment meets the following requirements:
- [PHP 8.0+](https://www.php.net/downloads)
- A local web server (Apache, Nginx, XAMPP, Laragon, etc.)
- [Composer](https://getcomposer.org/) (If managing Kirby plugins via Composer)
